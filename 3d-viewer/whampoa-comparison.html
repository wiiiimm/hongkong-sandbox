How this comparison is made

Identical scale, camera, ground and lighting. These are isolated model studies, not the live neighbourhood. The ship’s light mesh uses a one-metre clustering grid while protecting its upper silhouette. Site façades use an illustrative shared shader, without changing the source footprint or height. No surveyed window, paint or roof-detail accuracy is claimed.

Sizes are compressed model payloads, excluding shared viewer code. Site façade styling adds shared code, not a separate texture download. The existing high ship is not a new high-effort AI generation. Reviewed Site 8 and Site 12 geometry is also used in the main map. Lightweight variants remain comparison studies. Overview positions are arranged for comparison, not geographic placement.
