# Exact-output PolyU partition acceleration (isolated code proposal)

The running v1 helper/caller and its worker stay untouched. This proposal changes only future exact Fraction orchestration. It does not change source triangles, planes, packing, mask ownership, thresholds or acceptance. No actual source partition has been re-executed for this proposal.

Saved five-mask inputs contain 5,553 occurrences but 1,234 distinct ordered triangle/bounds/plane identities. Every original occurrence/provenance record remains present. Only identical ordered masks alias their earliest original occurrence. Once that mask removes its positive-area inside, each surviving positive-area fragment belongs to the ordered outside partition. Reapplying the identical ordered halfplanes cannot move or subdivide that fragment. Later clipping only restricts those fragments. Eliminating duplicate passes therefore preserves every ordered positive-area polygon and earliest mask owner; differently rotated/reversed representations are not aliased.

An exact rational bounding-volume tree nominates unique masks using strict closed-AABB disjointness and returns them in original first-occurrence order. Aliases expand back to the complete original relevant-ID list. Tree bounds use Fraction comparisons, with no floating broadphase or omission tolerance.

Halfplanes are multiplied only by a positive common exact scalar to obtain primitive integer coefficients. Signs, closed membership and rational intersection ratios stay identical. Entirely nonnegative clipping returns the original clean polygon. Entirely nonpositive clipping with a negative vertex returns that same outside polygon; the original inside is a zero-area line/point excluded by the existing partition caller. Strict straddling calls the unchanged clip. Area equality, own-plane checks and protected-literal rejection remain. The helper deliberately does NOT skip fragment-disjoint masks if v1 would create incidental outside subdivisions: that tempting shortcut would change ordered output/packing.

Fifteen actual synthetic fixtures passed, including 80 deterministic rational full-oracle comparisons and all ordered polygon/proof/packed-piece equality. Tests cover duplicate ownership, overlap, nested interior masks, closed point/edge contact, disjoint boxes, reordered plane cycles, layers, vertical/zero sources, non-dyadic packing and protected/degenerate failures. Synthetic timing (240 occurrences /12 unique) was 0.677s original versus0.0127s accelerated (53.2x excluding0.013s one-time compilation). This is synthetic timing, not an ETA guarantee for the actual parent facets.

It never calls either partition on actual source. Full intermediate candidate POSITION was not persisted, so the fixture will not claim to read that buffer. A future resumed caller must retain every saved partition row/ownership and reconstruct the same ordered prefix under independently reviewed lifecycle/input fences; fresh helper results are only for unfinished facets. Original worker termination/release and serial replacement belong to ROOT. No new worker/lease/DB/candidate/acceptance was started here.
