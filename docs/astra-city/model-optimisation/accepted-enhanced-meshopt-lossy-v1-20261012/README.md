# First lossy pilot — preserved, superseded

Codex, 12 October 2026. This 39-output pilot tested high/balanced/lightweight candidates on 13 installed sources spanning large landmarks, medium geometry and tiny assets. All original source assets remained unchanged; no reference-map images were used.

Position rounding created 682 / 1,426 / 16,449 newly zero-area faces across the high / balanced / lightweight samples. These diagnostics made the pilot unsuitable for expansion. The complete recipe, raw requests/results, separate immutable artifacts and exact producer bytes in `source-scripts/city/model-optimisation/lossy_codec_v1.mjs` are preserved. There are no Neon variant jobs or approved/published descriptors for this pilot.

The revised producer restores original positions whenever rounding collapses/reverses a face or creates area from an original zero-area face. Its separate pilot is recorded in `../accepted-enhanced-meshopt-lossy-v2-20261012/`; the user-authorised whole installed-source cohort is `../installed-enhanced-meshopt-variants-v2-20261012/`. These remain lossy candidates, with measured precision and achieved simplification rather than visually approved universal presets.
