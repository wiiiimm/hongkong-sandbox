# Installed hospital progress on HTTP/IP

Codex ran the existing nonsecure HTTP/IP progress verification in an isolated new output directory after installation of the unchanged Tuen Mun Hospital Special Block. Four desktop/mobile, stale and missing-data cases pass without page errors. The actual HTTP origin is `http://100.89.99.102:4176`; both secure context and SubtleCrypto are unavailable, so the shipped HTTP-compatible digest path is exercised.

Current counts: 346,108 source forms; 4,472 enhanced. No claims of unique physical-building counts. Current manifest and progress bytes, unchanged shipped scripts and original test source are pinned in `provenance.json`. The driver changes only module resolution and output location. Older frozen UI reports remain untouched.

No production UI implementation or model geometry was changed by this verification.
