          Statement: 
              The building footprint is normally mapped using field survey, digitization from old survey sheets, 
              conversion from building plans and/or photogrammetric techniques, delineating the ground-level outline 
              of structures that are visible above-ground.

              

              All entities within the Building Footprint sub theme are based on DAM Building CSU. The existing data 
              exchange process of the DAM Building CSU will be kept, and the data conversion process was conducted to 
              convert Building Data from DAM into the schema of the Building Footprint sub theme. A single unified 
              building structure layer is formed by combining all spatial entities in Building CSU which are based on 
              1:1000 digital map data from LandsD. Textual building geographical and structural information provided 
              by data owners of Building CSU (i.e. ArchSD, BD, LandsD, PlanD, RVD and HD) are also adopted.
