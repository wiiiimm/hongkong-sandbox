# Original lower surfaces inside a compound source assembly

Use this **diagnostic** when a saved compound-foundation check calls an original
upward facet buried beneath another original source. Its height sampler uses the
highest same-XZ surface: a higher roof can obscure a real matching lower floor.
Do not erase the original warning or presume that any covered surface is valid.

1. Reproduce the complete saved foundation counts and area with
   `selected_compound_buried_face_ids_v1_20261031.py`. It uses the identical source,
   peer, terrain and sample arrays in all four representations and names every
   fully flagged facet. Reuse this completed census by its exact hashes.
2. For an explicit owned batch, use
   `selected_shared_lower_floor_context_v1_20261031.py`. Saved positive-area
   original intersections nominate peer face IDs only. The tool independently
   reconstructs every represented source and peer, subtracts the nominated peer
   projections using exact rational arithmetic, and bounds all finite vertical
   gaps. No contact stream is recomputed wholesale.
3. Inspect the measured result. Missing coverage or an out-of-range gap is a
   completed negative diagnostic, not a corrupt model or an installation decision.
   Zero uncovered area and the existing strict native interface interval give
   source-role context; they do not replace identity, actual terrain clearance,
   every other source facet, full neighbour/support checks, real runtime evidence,
   ownership, review snapshot or guarded publication.

The interval retains the actual existing IEEE -0.1 and 1 metre limits. Literal
coordinates can have small nonzero offsets even when the rendered Float32
surfaces coincide; those offsets remain in the exact proof. No snapping, buffer,
coverage epsilon, vertex edit, invented root or terrain alteration is allowed.
Seven kernel tests cover split floors, missing peers, a subnanometre coverage hole,
wall misclassification, and the exact interval endpoints plus their next floats.
